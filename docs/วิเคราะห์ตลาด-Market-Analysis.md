# วิเคราะห์ตลาด (Market Analysis)

**โปรเจค:** IIoT OEE Monitoring Dashboard (Conveyor Belt Model)  
**วัตถุประสงค์เอกสารนี้:** สรุปข้อมูลตลาดจริงที่เกี่ยวข้อง เพื่อประเมินว่าตลาดต้องการระบบแบบนี้หรือไม่ และควรเจาะกลุ่มเป้าหมายใดก่อน  
**แหล่งข้อมูล:** สรุปจากการสืบค้นเว็บ (สิงหาคม 2026) — ดูรายการอ้างอิงท้ายเอกสาร

## 1. สรุปภาพรวมตลาด

### 1.1 ตลาดโลก (Global OEE Monitoring System Market)

| ปี | มูลค่าตลาด | หมายเหตุ |
| --- | --- | --- |
| 2023 | ~786 ล้านดอลลาร์สหรัฐ | ฐานปีเริ่มต้น |
| 2025 | ~801 ล้านดอลลาร์สหรัฐ | ประมาณการ |

- **CAGR:** ประมาณ 4.6–4.8% ต่อปี (2023–2034)
- แรงขับเคลื่อนหลัก: ความต้องการลด Downtime, เพิ่มผลิตภาพ, ควบคุมคุณภาพเข้มงวดขึ้น
- แบ่งตามประเภทระบบ: **On-Premises** และ **Cloud-Based** — ตลาดรายงานชี้ว่า **Cloud-Based ได้รับความนิยมในกลุ่ม SME มากกว่า** เพราะต้นทุนเริ่มต้นต่ำและดูแลง่ายกว่า

### 1.2 ตลาดไทย

- ไม่มีตัวเลขมูลค่าตลาด OEE เฉพาะของไทยที่เผยแพร่ตรง ๆ แต่มีสัญญาณตลาดชัดเจนผ่านผู้ให้บริการและงานวิจัยที่เกี่ยวข้อง
- เทรนด์เด่นปี 2026: **"Modular IoT Retrofitting"** — ติดเซนเซอร์ภายนอกเข้ากับเครื่องจักรเก่า (อายุ 15–20 ปี) โดยไม่แก้ไขระบบไฟฟ้า/PLC เดิม
- แรงผลักดัน: Krungsri Research ระบุว่าผู้ผลิตไทยเผชิญแรงกดดันด้านต้นทุน ทำให้การซื้อเครื่องจักรใหม่ราคาหลักล้านบาทไม่สมเหตุสมผล จึงหันมาใช้ Retrofit ราคาถูกแทน

## 3. ความต้องการของตลาด (Demand Signals)

หลักฐานที่ชี้ว่าตลาดต้องการระบบแบบนี้:

1. **แรงกดดันต้นทุนในภาคการผลิตไทย** ทำให้ SME หันมาใช้ Retrofit เซนเซอร์ราคาถูกแทนซื้อเครื่องใหม่
2. **Cloud-Based OEE System ถูกระบุว่าตรงกับความต้องการ SME** เพราะต้นทุนเริ่มต้นต่ำ ไม่ต้องมีทีม IT ในองค์กร
3. **ROI ที่ตลาดยอมรับอยู่ที่ 3 เดือน–1 ปี** ซึ่งระบบต้นทุนต่ำแบบนี้มีโอกาสคืนทุนเร็วกว่าแพ็กเกจราคาแพง
4. **มีผู้ให้บริการเชิงพาณิชย์อยู่แล้วในตลาดไทย** (ENT Group, Mitsubishi Electric) แสดงว่าดีมานด์มีอยู่จริง ไม่ใช่ตลาดสมมติ
5. **บทความ/เคสศึกษาปี 2026 พูดถึง Modular IoT Retrofitting โดยเฉพาะ** แสดงว่าเป็นเทรนด์ที่กำลังมา ไม่ใช่แนวคิดล้าสมัย

## 5. กลุ่มเป้าหมายที่แนะนำ (Target Segmentation)

### 5.1 กลุ่มหลัก (Primary — ควรเริ่มก่อน)

**A. โรงงาน SME ขนาดเล็กมาก (Micro-Manufacturing)**
- มีสายพาน 1–3 ไลน์ ยังนับข้อมูลด้วยมือ/กระดาษ
- งบลงทุนต่ำกว่าหลักแสนบาทมาก
- ไม่มีทีม IT ในองค์กร ต้องการระบบที่ติดตั้งแล้วใช้ได้ทันที
- Pain point ตรงกับจุดแข็งของโปรเจคนี้โดยตรง (ราคาต่ำ + ใช้งานได้จริง)

**B. สถานศึกษาสายอาชีวะ/เทคนิค**
- ต้องการชุดฝึกอบรม IIoT/OEE สำหรับการเรียนการสอน
- งบเป็นของสถานศึกษา ไม่ใช่เงินเสี่ยงของโรงงาน ตัดสินใจซื้อง่ายกว่า
- ขายในรูปแบบ "ชุดปฏิบัติการ IIoT" ราคาต่อชุดระดับหลักพัน–หลักหมื่นบาท

### 5.2 กลุ่มรอง (Secondary — ขยายในระยะต่อไป)

**C. System Integrator (SI) รายเล็ก / Maker**
- ต้องการ Reference Design ไปต่อยอดขายลูกค้าของตนเอง
- ขายในรูปแบบ Open-source template + บริการปรับแต่ง (customize)

**D. โรงงานที่มีเครื่องจักรเก่า (Legacy Machine Retrofitting)**
- ตรงกับเทรนด์ Modular IoT Retrofitting ที่กำลังมาในตลาดไทยปี 2026
- ต้องเพิ่มความทนทานของระบบ (ดู Phase C ในเอกสารแผนพัฒนาต่อยอด) ก่อนเข้าตลาดกลุ่มนี้จริงจัง

### 5.3 กลุ่มที่ยังไม่ควรเจาะในระยะนี้ (Not Yet)

**E. โรงงานขนาดกลาง–ใหญ่ที่ใช้ PLC/SCADA อยู่แล้ว**
- คู่แข่งคือแบรนด์ระดับ Mitsubishi Electric, Siemens ซึ่งมีความน่าเชื่อถือและซัพพอร์ตที่สูงกว่ามาก
- ควรรอจนกว่าระบบพัฒนาไปถึงระดับ Phase C/D (มี PCB, ประกัน, ซัพพอร์ตต่อเนื่อง) ตามแผนพัฒนาต่อยอด

## 7. ความเสี่ยงและข้อจำกัดของตลาด (ไม่อวย)

1. **ความน่าเชื่อถือของระบบ homemade** — โรงงานยังกังวลว่าระบบที่ไม่มีแบรนด์รองรับจะเสถียรพอหรือไม่ ต้องพิสูจน์ผ่านการใช้งานต่อเนื่องก่อน (Phase B)
2. **การซัพพอร์ตหลังการขาย** — คู่แข่งมีทีมซัพพอร์ตภาษาไทย 24/7 และสต็อกอะไหล่ในประเทศ ผู้จัดทำคนเดียวสู้ได้ยากในช่วงแรก ควรเริ่มจากกลุ่มที่ยอมรับความเสี่ยงได้มากกว่า (สถานศึกษา, Micro-SME ที่คุ้นเคยกัน)
3. **การพึ่งพา Cloud ภายนอก** — ใช้ HiveMQ Cloud ซึ่งบางโรงงานอาจกังวลเรื่องข้อมูลออกนอกองค์กร ควรมีตัวเลือกใช้ MQTT Broker ภายในองค์กร (on-premise) ด้วย
4. **การแข่งขันจากชุด DIY ทั่วไปในตลาดออนไลน์** — มีชุดเซนเซอร์ราคาถูกขายอยู่แล้วในแพลตฟอร์มอีคอมเมิร์ซ จุดขายของโปรเจคนี้ต้องเป็น "ระบบ OEE พร้อมใช้ครบวงจร" ไม่ใช่แค่ขายฮาร์ดแวร์เปล่า

## 8. สรุป

**ตลาดต้องการระบบแบบนี้จริง** เนื่องจาก SME ไทยกำลังมองหาทางเลี่ยงการลงทุนเครื่องจักรใหม่ราคาสูง ด้วยการทำ Retrofit เซนเซอร์ราคาประหยัด และตลาด OEE Monitoring ทั่วโลกก็เติบโตต่อเนื่องในระยะยาว

**กลุ่มที่ควรเจาะก่อน:**
1. สถานศึกษาสายอาชีวะ (ตัดสินใจซื้อง่ายที่สุด)
2. Micro-SME ที่มีสายพาน 1–3 ไลน์ (Pain point ตรงที่สุด)

**กลุ่มที่ค่อยขยายทีหลัง:** Legacy Machine Retrofitting และ System Integrator รายเล็ก

**จุดขายหลัก:** ราคาต้นทุนต่ำกว่าคู่แข่งในตลาดอย่างมีนัยสำคัญ แต่ต้องพัฒนาความน่าเชื่อถือของระบบ (Phase B–C) ก่อนเข้าสู่กลุ่มลูกค้าโรงงานที่มีความเสี่ยงสูงขึ้น

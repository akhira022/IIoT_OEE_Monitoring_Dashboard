# เอกสารรายงานโปรเจค (รูปแบบ ปวส.)

**ชื่อโปรเจค:** ระบบตรวจสอบประสิทธิภาพสายพานลำเลียงอัจฉริยะแบบเรียลไทม์ด้วยสถาปัตยกรรม IIoT และดัชนี OEE  
**ชื่อภาษาอังกฤษ:** Smart Conveyor Belt Real-Time OEE Monitoring Dashboard using IIoT

## วิธีนำไปใช้เขียนเล่มรายงาน

1. คัดลอกเนื้อหาแต่ละบทไปใส่เทมเพลตของวิทยาลัย (Word / Google Docs)
2. เติมชื่อผู้จัดทำ รหัสนักศึกษา ชื่ออาจารย์ที่ปรึกษา และปีการศึกษาที่ปก
3. ใส่รูปจริงของชุดสาธิต กราฟ Grafana และตารางผลการทดลองในบทที่ 4
4. ปรับคำให้เข้าสำนวนรายงานวิชาการของสถานศึกษา (ถ้าต้องการน้ำเสียงทางการมากขึ้น)
